# E3.4, the intra-rater re-coding of the literature survey: deferred

The plan (`EXPERIMENTOS_2026-09-27.md`) sets E3.4 to start **no earlier than 7 October 2026**, at least
two weeks after the first coding, and requires the 20 studies to be re-coded **without opening the
earlier codes**. It was therefore not run on 27 September 2026.

A note for whoever runs it. The first coding was done in an earlier session of the same AI assistant,
and the earlier codes, with their quoted sentences, are in this repository
(`experiments/_results/trap_literature_survey/result.json`). A re-coding by that assistant can be
blind only if the session is given the studies and the coding rules but not the repository. Even then
it is an intra-rater check at best, as the paper says, and not a substitute for an independent second
coder.
